# Darsel AI Solver 🧠📲
### روبوت الذكاء الاصطناعي لحل أسئلة منصة Darsel على واتساب تلقائياً (نصوص وصور)

بوت واتساب ذكي مدعوم بأحدث نماذج **Google Gemini 3.5 Flash** لحل المسائل الرياضية، التمارين العلمية، والأسئلة (نصوص + صور) الواردة من منصة **Darsel (+1 202 773-7838)** وإرسال الحل الصحيح فوراً بالصيغة التي يقبلها النظام الآلي.

---

## 🌟 المميزات الرئيسية:
1. **حل ذكي للصور والنصوص (Multimodal):**
   - يقرأ صور المسائل الرياضية، المثلثات، الرسوم البيانية، والواجبات بدقة فائقة.
   - يحل الأسئلة خطوة بخطوة ويرسل الإجابة المباشرة (رقم الخيار، القيمة العددية، كلمة التأكيد).
2. **عزل وأمان تام للخصوصية (Target Isolation):**
   - البوت مبرمج ليتفاعل **فقط مع رقم Darsel (+1 202 773-7838)**.
   - يتجاهل تماماً أي محادثة أو مكالمة أو مجموعة شخصية أخرى.
3. **لوحة تحكم خفيفة للموبايل (Mobile Dashboard):**
   - صفحة ويب مصممة خصيصاً للموبايل لمتابعة الأسئلة والأجوبة لحظة بلحظة.
   - زر لتشغيل أو إيقاف الرد التلقائي بلمسة واحدة.
4. **ربط مباشر بدون كاميرا (Pairing Code):**
   - لا حاجة لمسح QR Code من جهاز ثانٍ.
   - فقط اكتب رقم هاتفك في لوحة التحكم، وستحصل على **كود اقتران من 8 أرقام** تدخله في واتساب مباشرة من نفس الهاتف!

---

## 🚀 طريقة الرفع على نورث فلانك (Northflank) في دقيقة واحدة:

1. افتح موقع **[Northflank](https://northflank.com)** وسجل الدخول بحساب GitHub الخاص بك.
2. أنشئ مشروعاً جديداً **(Create Project)**.
3. اختر **Create Service** > ثم **Deployment Service**.
4. اختر **GitHub** وحدد هذا المستودع:
   ```
   ahmadd1g2017-code/whatsapp-ai-solver
   ```
5. في قسم **Build settings**:
   - اختر **Dockerfile** (سيكتشف ملف Dockerfile المرفق تلقائياً).
6. في قسم **Networking**:
   - أضف منفذ **Port 3000** مع تفعيل **Public HTTP**.
7. اضغط **Deploy Service**!
8. بمجرد انتهاء البناء، اضغط على الرابط العام للخدمة من هاتفك:
   - أدخل رقم هاتفك على الواتساب.
   - اضغط **"الحصول على كود الاقتران"**.
   - افتح واتساب > **الأجهزة المرتبطة** > **ربط باستخدام رقم الهاتف** > اكتب الكود!
   - مبروك! البوت الآن يحل كل أسئلة Darsel تلقائياً 24/7 دون أي استهلاك لهاتفك!
